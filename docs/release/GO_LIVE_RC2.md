## 6. Проверка robots.txt и sitemap (~5 мин)

**Сделать.** `curl -s https://rubizh.shop/robots.txt` — совпадает с файлом из архива: нет отдельной строки `Disallow: /`
(стейджинговый файл), есть строка `Sitemap:`; то же с `curl -A Googlebot -s https://rubizh.shop/robots.txt` (блок хостинга adm.tools, S5-4,

появятся только после шага 8 — здесь их не ждать.

**Успех.** robots — из архива, sitemap 200, noindex нет. **Если нет.** Закрытый режим не выключен (шаг 4) или блок хостинга перекрывает файл — исправить и повторить.
